 Customer Shopping Behavior Analytics

**Python (pandas/seaborn) + MySQL + Power BI** end-to-end data analytics project.

## Project Structure
```
customer_shopping_analysis/
├── README.md
├── data/
│   ├── customer_shopping_behavior.csv      # raw dataset (3,900 records)
│   └── shopping_analytics.db               # SQLite DB (auto-generated by notebook)
├── notebooks/
│   └── customer_shopping_analysis.ipynb    # full pipeline, pre-executed with outputs
├── sql/
│   ├── 01_create_database.sql              # MySQL schema
│   └── 02_analysis_queries.sql             # 12 analytical MySQL queries
├── charts/                                  # exported PNG charts from EDA
└── powerbi/
    └── customer_shopping_cleaned.csv       # cleaned data ready for Power BI import
```

## Pipeline
1. **Load & Clean** — pandas: standardize column names, drop duplicates/nulls, fix dtypes.
2. **EDA** — seaborn/matplotlib: distributions, revenue by category/season, gender spend, correlation heatmap.
3. **Load into SQL** — notebook loads cleaned data into a local SQLite DB so it runs end-to-end without a server; `sql/01_create_database.sql` gives the equivalent MySQL schema.
4. **SQL Analysis** — 12 analytical queries (`sql/02_analysis_queries.sql`) covering category revenue, top locations, age segments, discount/promo impact, subscription behavior, payment methods, and more.
5. **Power BI Export** — cleaned dataset exported to `powerbi/customer_shopping_cleaned.csv` for direct import, or connect Power BI live to MySQL.

## How to Run
1. `pip install pandas numpy matplotlib seaborn sqlalchemy pymysql`
2. Open `notebooks/customer_shopping_analysis.ipynb` in Jupyter — runs top to bottom with no external setup (uses SQLite).
3. **To use real MySQL instead:**
   - Run `sql/01_create_database.sql` in MySQL Workbench/CLI.
   - Uncomment the MySQL engine cell in Section 5B of the notebook and add your credentials.
   - Run `sql/02_analysis_queries.sql` directly in MySQL Workbench.
4. Open Power BI Desktop → **Get Data** → **Text/CSV** → select `powerbi/customer_shopping_cleaned.csv` (or connect directly to MySQL database `shopping_analytics`).

## Power BI Dashboard Ideas
- KPI cards: Total Revenue, Total Orders, Avg Order Value, Avg Rating
- Bar chart: Revenue by Category
- Column/line chart: Revenue by Season
- Map: Revenue by Location
- Donut: Subscription Status split
- Table: Top 10 customers by spend
- Slicers: gender, season, category, subscription_status

## Key Findings
- Clothing and Footwear generate the highest total revenue.
- Revenue is fairly even across seasons with a slight Fall/Winter uptick.
- Discounted orders show higher volume but similar review ratings — discounts drive volume, not necessarily satisfaction.
- Subscribed customers have higher average previous purchase counts, signaling stronger retention.
- Credit Card, PayPal, and Cash are the leading payment methods.
